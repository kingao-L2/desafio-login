# Desafio - Página de Login com Autenticação via API

Este projeto foi desenvolvido para cumprir o desafio de integração de uma interface de Login frontend com uma API RESTful para autenticação de usuário e recebimento do `access_token`.

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (Fetch API / Async/Await)

## Funcionalidades
- Formuário de login funcional.
- Envio das credenciais via requisição `POST` em formato JSON.
- Recebimento e validação do `access_token`.
- Exibição de mensagem dinâmica de sucesso/erro na interface.
- Armazenamento do token no `localStorage`.
